# マグネットネイル × MRI — 実験発表の組み立て案（実機主軸版）

**前提**
- 1.5T と 3T の両方が使用可能、業務終了後の撮影枠は実質無制限
- MRI対応の光ファイバー温度計は無し（発熱の扱いは後述の代替法）
- 発表先: 科学コンテスト／研究発表会レベル（学会発表にも耐える設計にしてある）

---

## 0. 設計方針 — 何が変わったか

撮影枠が制約でなくなったことで、この研究は **「自宅実験＋実機で答え合わせ」から「実機での正規試験」** に格上げできます。具体的には:

1. **吸引力を実機で測れる。** 卓上の磁石で代用する必要がなく、実際のガントリー入口の最大空間磁場勾配位置で測定できる。これは ASTM F2052（MRI用具の磁気吸引力試験の国際標準）そのものの条件です。
2. **磁場強度依存性を示せる。** 1.5T と 3T の比較は、他の誰にも簡単には真似できない差別化点。磁化率アーチファクトは B₀ にほぼ比例し、RF発熱は周波数依存なので、**同じ試料で両方測るだけで論文1本分の骨格**になります。
3. **量反応関係を描ける。** TE、受信バンド幅、シーケンス、配置角度、距離 — すべて振れる。点の比較ではなく**曲線**を出せるのが最大の武器です。
4. **n を稼げる。** 反復測定で平均±SD とエラーバー、統計検定まで持っていける。ここで発表の質が決まります。

**発熱だけは制約が残ります。** 光ファイバー温度計が無いと ASTM F2182 準拠のRF発熱測定はできません。→ 後述の「不可逆性示温ラベル」で最高到達温度を記録する方法に切り替え、**限界を正直に書いたうえで補助的な位置づけ**にします。主軸は画像と吸引力です。

## 1. 研究の問い — 3階層に整理する

この研究の価値は、現場の「マグネットネイルはオフしてください」という運用が、**どこまで根拠があり、どこからが過剰なのか**を切り分けることにあります。問いを3階層で立てると発表の筋が通ります。

| 階層 | 問い | 答えを出す実験 |
|---|---|---|
| **Q1 物理** | マグネットネイルは、どの経路で・どれだけMRIに干渉するのか | 案A（吸引力）・案B（画像）・案C（発熱） |
| **Q2 条件** | その干渉は、磁場強度・シーケンス・撮影部位からの距離でどう変わるのか | 案D（多因子マトリクス） |
| **Q3 運用** | では、どういうルールが妥当なのか。全例オフは必要か | 案E（プロトコル提案） |

**Q3 まで到達できるのがこの研究の強み**です。技師長の立場で実際に運用ルールを作れるので、「提案しました」で終わらず「自施設で運用を変えました」まで書けます。発表の締めとしてこれ以上のものはありません。

## 2. 前提知識の整理

### マグネットネイルの仕組み
ジェル液中に微細な磁性フレーク（磁石に反応する金属の薄片。多くは酸化鉄系または鉄ニッケル合金）が分散している。磁石を近づけると粉が磁力線に沿って整列し、光の反射が変わって「猫目（キャッツアイ）」状の帯ができる。UVライトで硬化させると**その配列が固定されたまま残る**。

→ 重要: 完成品は「磁性粉が特定方向に揃って固まっている」状態。これが案D（異方性）の物理的根拠です。

### 干渉の4経路

| # | 経路 | 機序 | 本研究での扱い |
|---|---|---|---|
| ① | 吸引力・トルク | 空間磁場勾配 ∂B/∂z が磁性体を引く／揃えようとする | **主軸**（ASTM F2052 / F2213 準拠） |
| ② | 画像アーチファクト | 磁化率差による局所磁場不均一 → 信号消失・幾何学的歪み | **主軸**（ASTM F2119 準拠） |
| ③ | RF発熱 | 導電性フレークへの渦電流誘導 | 補助（温度計制約のため代替法） |
| ④ | モニタ干渉 | パルスオキシメータの光学的遮蔽 | 副次テーマ（案F） |

用語注:
- **ASTM** … 米国材料試験協会。MRI環境での医療機器・物体の安全性試験法を一連の規格として定めており、MR Conditional 表示の根拠になっている。
- **ネイルチップ** … 付け爪。実験では規格の揃った試験体として使える（爪の個体差を排除できる）。
- **不可逆性示温ラベル** … 一定温度に達すると色が変わり、冷えても戻らないシール。最高到達温度が記録として残る。

## 3. 実験計画

### 案A：磁気吸引力・トルク — ASTM F2052 / F2213 準拠【主軸1】

**問い**: マグネットネイルは、爪から剥離するほどの磁気力を受けるのか。

**仮説**: 通常のカラージェルは偏向角がほぼ0°である一方、マグネットネイルは測定可能な偏向角を示す。ただし試料質量が小さいため、絶対的な力は剥離閾値を下回る。

**方法（偏向角法）**
1. 試料を軽量の糸で吊るした治具を作る。
2. **ガントリー入口の最大空間磁場勾配位置**に治具を設置。メーカーの磁場勾配マップから ∂B/∂z が最大となる位置を読み取る。
   注意: **ガウスラインマップ（磁場強度の等高線）と空間磁場勾配マップは別物**です。吸引力を決めるのは B ではなく B·(∂B/∂z) なので、必ず勾配側を参照してください。最大勾配位置は多くの装置でボア入口付近の体軸上ですが、機種差があります。マップ上の位置を、簡易的な吸引力の確認（非磁性治具に吊した試験片の振れが最大になる点を探る）で実測確認しておくと、測定位置の妥当性を発表で主張できます。
3. 静磁場によって糸が傾く角度 θ を測定。
4. 磁気力 **F = m·g·tan θ**（m=質量、g=重力加速度）
5. **判定基準**: ASTM F2052 は θ < 45° を「磁気力が重力以下＝一般に許容可能」とする。→ **「マグネットネイルの偏向角は45°を超えるか」という、規格に裏打ちされた白黒のつく問いが立つ。** これは発表のキャッチとして極めて強い。
6. トルク（ASTM F2213）は、試料を低摩擦の台に載せて磁場中で回転するかを観察。定量が難しければ定性評価でよい。

**測定条件**: 1.5T × 3T、各試料 n=10。
**試料群**: 透明ジェル／通常カラージェル／ラメ入り／マグネットネイル（磁石未使用で硬化）／マグネットネイル（磁石で模様付け後に硬化）／各製品10種以上

**発表上の強み**: 偏向角が45°未満なら「**吸引力の観点では剥離リスクは低い**」と規格準拠で言い切れる。現場の不安を一つ消せる。逆に超えるなら重大な知見。どちらに転んでも発表が成立する設計です。

### 案B：画像アーチファクト — ASTM F2119 準拠【主軸2・クライマックス】

**問い**: アーチファクトはどの範囲に及び、何で決まるのか。

**仮説**: 信号消失域は磁性粉量と B₀ と TE に比例して拡大し、GRE系ではSE系の数倍に達する。ただし磁場の乱れは距離とともに急速に減衰するため、**撮影部位から一定距離以上離れていれば臨床的に無視できる**。

**方法**
1. 硫酸銅水溶液または寒天ファントムを用意。ネイルチップを規則配置して固定。
2. **ASTM F2119 の定義でアーチファクトを測定**: 試料なしの参照画像との画素値の差が30%を超える領域をアーチファクトとし、その最大径と面積を計測。ImageJ で閾値処理して自動計測すれば客観性・再現性が担保できる。
3. 撮影マトリクス（枠が無制限だからこそできる網羅）:

| 因子 | 水準 |
|---|---|
| 磁場強度 | 1.5T / 3T |
| シーケンス | SE / TSE / GRE / EPI / 脂肪抑制 |
| TE | GREで4〜5段階に振る（**量反応曲線が描ける**） |
| 受信バンド幅 | 2〜3段階（実務的な低減策の検証） |
| 周波数エンコード方向 | 2方向 |
| 試料からの距離 | 0 / 2 / 5 / 10 / 20 cm |
| 配置角度 | 0° / 45° / 90°（案Dと共有） |

4. **金属アーチファクト低減シーケンス**（VAT / SEMAC / MAVRIC 等）が自施設にあれば必ず検証。「**オフしなくても撮れる条件はあるか**」という、現場が最も知りたい問いに直接答えられます。

**この案の隠れた本命 — 距離依存性**
現場で最も多い疑問は「**頭部MRIで手のネイルは関係あるのか**」です。磁化率による磁場の乱れは距離とともに急速に減衰するので、撮影部位から離れていれば画像には実質影響しないはずです。一方で吸引力と発熱は距離が違う話になります。**この切り分けこそが、この研究が現場に返せる最大の答え**です。

→ 「手指・手関節MRIでは除去必須、頭部・体幹部では画像的には問題なし。ただし発熱の観点から別途評価が必要」という、部位別の運用指針に直結します。

### 案C：発熱 — 制約下での最善手【補助】

光ファイバー温度計が無いため、ASTM F2182 準拠の測定はできません。以下で代替します。

**方法（不可逆性示温ラベル法）**
1. 試料に **不可逆性示温ラベルを複数温度段（40 / 45 / 50 / 55 / 60℃）貼付**。冷えても色が戻らないため、撮影後の遅延に影響されず**最高到達温度が記録として残る**。これが遅延測定の弱点を回避する鍵です。
2. 高SARシーケンス（TSE、大フリップ角、短TR）を長時間連続実行し、熱負荷を最大化。
3. 1.5T と 3T の両方で実施。
4. 補助として、ガントリーから出した直後に非接触赤外温度計で測定（遅延による過小評価であることを明記）。

**限界の明記（これを書くことが評価される）**
- 温度の時間変化が取れないため、上昇速度・定常値・時定数は不明。
- ファントムの熱伝導は生体の血流による冷却を再現していないため、**生体では本法より低い温度になる可能性が高い**（＝安全側の評価）。
- 光ファイバー温度計を用いた ASTM F2182 準拠測定は今後の課題、と明記する。

**発表上の扱い**: 「示温ラベルが40℃段階でも変色しなかった」なら、それ自体が十分に有用な陰性所見です。無理に主軸に据えず、**限界を明示した補助データ**として置くのが誠実で、かつ審査員の心証も良くなります。

### 案D：配向異方性 — 独自性の核【差別化】

**問い**: 硬化時に磁性粉を整列させた「向き」は、MRIへの影響を変えるか。

**仮説**: 磁性フレークが一方向に整列していることで異方性が生じ、静磁場に対する配置角度によって吸引力もアーチファクトの形状も変化する。

**方法**: 同一製品・同一塗布量で、磁石の当て方のみを変えた試料（縦配列／横配列／斜め／未配列）を作製。各々について B₀ に対し 0° / 45° / 90° で、偏向角とアーチファクト形状を測定。

**なぜ重要か**: 先行研究はすべて「磁性粉を含む化粧品」として扱っており、**「粉が揃って固まっている」というマグネットネイル固有の物理を検討したものは見当たりません。** ここが新規性の主張点です。

**リスク**: 差が小さく有意にならない可能性。→ 案A・Bが土台としてあるので、空振りでも発表は揺らぎません。「有意差なし」も**整列は影響しないという知見**として報告価値があります。

### 案E：運用プロトコルの提案と実装【最終成果物】

**問い**: 全例を延期して除去させる運用は妥当か。妥当でないなら、どういうルールが適切か。

自施設の運用は**中止ではなく延期**（除去後に再予約）です。この違いは重要で、損失の中身が「検査が実施されない」ことではなく **「診断が遅れる」「患者が二度来る」** ことになります。調査項目はそこに合わせて設計します。

**構成要素**

**E-1. 実態調査 — 延期の代償を数字にする（技師長だからこそできる・最優先）**

予約・実施記録から後ろ向きに集計します。順に効きます。

| 指標 | なぜ効くか |
|---|---|
| 年間の延期件数 | 問題の規模。導入の第一声になる |
| **依頼日（または初回予約日）から実施日までの日数** | **診断の遅れの直接指標。この研究で最も説得力のある数字** |
| 延期後、**再予約に至らなかった／実施されないまま脱落した例** | 最も深刻。安全のための運用が**未受検という別のリスク**を生んでいることになる |
| 延期部位の内訳（頭部／体幹部／四肢） | 案Bの距離依存性の結果と突き合わせれば、**そのうち何件が本来不要だったか**が言える |
| 空いた枠が当日埋められたか | 施設側の稼働損失 |
| 患者側の負担 | 再来院の時間・交通費、ジェルオフの費用（自力では除去困難で、サロン費用が発生する） |

**部位別の内訳を取ることが鍵**です。案Bで「頭部MRIでは画像的に問題なし」という結果が出れば、延期件数のうち頭部症例の割合がそのまま **「回避できたはずの遅れ」** として提示できます。導入の数字と結論が直結します。

**E-2. 問診の限界という論点（追加）**

延期の判断は問診や受付での確認に依存しているはずですが、ここに構造的な弱点があります。**患者の多くは、自分のネイルがマグネットタイプかどうかを知らない／区別できない**という点です。「ジェルネイルですか」と聞いても、磁性粉の有無は答えられません。サロンで施術された場合はなおさらです。

→ つまり現行運用は「ジェルネイルなら一律延期」に倒さざるを得ない構造になっている。**これが過剰な延期を生んでいる根本原因**であり、簡易判定法の必要性の根拠になります。この論点を立てられると、案E-3が「あれば便利」から「無いと解決しない」に格上げされます。

実態調査の際、問診票の記載と実際のネイル種別が一致していたかを確認できれば、**問診の感度・特異度**として定量できます。

**E-3. 簡易スクリーニング法の検証**

冷蔵庫マグネット程度の弱磁石への反応の有無を、案A/Bの結果を正解ラベルとして**感度・特異度**（見逃しの少なさ・空振りの少なさ）で評価。受付や更衣室で数秒で判定でき、患者の自己申告に依存しない。予約時の電話問診では判別できない層をここで拾えます。

**E-4. 部位別・条件別の判定フローチャート**を作成。

**E-5. 試験運用と効果測定**

自施設で試験運用し、**アウトカムを前後比較**します。
- 主要指標: **延期率**、および**依頼日から実施日までの日数（中央値）**
- 副次指標: 脱落例の減少、枠稼働率

ここまで到達できれば、「提案しました」ではなく **「運用を変えて、診断までの日数が◯日短縮した」** と言えます。発表の締めとしてこれ以上のものはありません。

---

### 案F：パルスオキシメータへの干渉【副次】

検査中の患者監視で指にパルスオキシメータを装着する以上、ネイルによる光学的遮蔽は実在の論点です。市販のオキシメータで、色別・ラメ有無別・マグネット有無別に SpO₂ と灌流指標（PI）を測定。装着部位を側面に変更することで回避できるかも検証。「**リスクは磁場だけではない**」という考察の厚みが出ます。
※ 被験者を伴う測定は、自施設の倫理手続きに従ってください。

## 4. 推奨する全体構成

```
 【導入】延期の実態 — 件数・診断までの日数・部位別内訳（案E-1）
            ↓
 【物理】案A 吸引力（ASTM F2052）  ─┬─ 1.5T vs 3T
        案B 画像（ASTM F2119）    ─┤   ← クライマックス
        案C 発熱（示温ラベル）      ─┘
            ↓
 【条件】案B 距離依存性・シーケンス依存性 → 部位別の切り分け
        案D 配向異方性 → 新規性
            ↓
 【運用】案E 判定法＋部位別指針 → 試験運用 → 延期率と実施までの日数の変化
```

導入と結論が**自施設の実データで閉じる**のがこの構成の要点です。「現場の困りごと → 物理的検証 → 現場の解決」という円環になり、研究として完結します。

さらに、**導入で出した部位別内訳と、案Bの距離依存性の結果が結論で噛み合う**ように設計してあります。「延期の◯割は頭部症例だった」→「頭部では画像的影響は認められなかった」→「その◯割は回避できた」という流れが一本で通ります。

**タイトル案**
- 「マグネットネイル装着者のMRI検査は一律に中止すべきか — 1.5T/3Tにおける吸引力と画像アーチファクトの定量評価」
- 「猫目の正体 — 整列した磁性粉がMRIに与える影響と、部位別運用指針の提案」
- 「『ネイルはオフしてください』の根拠を測る」

| 10 | 結果① | 製品別・磁場強度別の偏向角（45°の基準線を引く）。エラーバー必須 |
| 11 | 結果② | **MRI画像の比較 — 最大の見せ場**。1.5T vs 3T、GRE vs SE を並べる |
| 12 | 結果③ | TE依存の量反応曲線、シーケンス別の信号消失面積 |
| 13 | 結果④ | **距離依存性のグラフ — 本研究の核心**。部位別の切り分けがここで決まる |
| 14 | 結果⑤ | 配向異方性（案D）、発熱（示温ラベル、限界を明示） |
| 15 | 考察 | 4経路のどれが実際に効いているか。臨床的な意味づけ |
| 16 | 限界 | ファントムであり生体ではない、温度計の制約、製品数、装置2台のみ |
| 17 | 提案 | 簡易判定法（感度・特異度）と部位別フローチャート |
| 18 | 試験運用の結果 | 延期率と実施までの日数の前後比較 |
| 19 | まとめ・謝辞 | |

**見せ場は11枚目と13枚目**です。11枚目の画像で「確かに影響はある」と納得させ、13枚目の距離依存性で「ただし部位による」と反転させる。この落差が発表の山になります。

## 6. 統計の設計（ここで差がつく）

- 各条件 **n=10** 以上。枠が無制限である利点をここに全投入する。
- 平均 ± 標準偏差、**95%信頼区間**を併記。エラーバーのないグラフは出さない。
- 磁場強度×シーケンス×製品のような多因子比較には**二元配置分散分析**（複数の要因の影響を同時に評価する手法）、同一試料を繰り返し測る場合は**反復測定分散分析**。
- 多重比較には Bonferroni 補正など（比較を繰り返すと偶然の有意差が出やすくなるため、基準を厳しくする補正）。
- 案E-2 の簡易テストは**感度・特異度・ROC曲線**で評価。
- 測定者間・測定日間の再現性を一部条件で確認しておくと、信頼性の主張が強くなります。

## 7. 安全管理

実機を自由に使える立場であればこそ、記録に残る形で管理してください。

1. **人体でのMRI撮影は行わない。ファントムのみ。** 自分の手であっても撮影しない。
2. **ネオジム磁石を検査室に持ち込まない。** 模様付けと硬化は検査室外で完了させ、硬化済み試料のみを持ち込む。
3. 全試料は**確実に固定し、回収用の索を付ける。** 微小な試料でも吸着の可能性を前提に扱う。
4. 金属を含む温度計・工具・治具を持ち込まない。治具は樹脂・木材・非磁性材で自作する。
5. 時間外の単独作業を避け、**2名以上**で実施する。緊急時の対応者を確保しておく。
6. 実施ごとに日時・装置・条件・試料・立会者を記録に残す。
7. 中止基準を事前に定める（異音、試料のズレ、示温ラベルの想定外の変色を認めたら即中断）。
8. 施設名・装置機種の公表可否、および実態調査データの取り扱いについて、事前に院内の承認を得る。

## 9. 着手順
