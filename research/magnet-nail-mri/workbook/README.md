## 数式の検証について

この環境では Excel / LibreOffice による再計算ができなかったため、
Python の Excel 数式評価エンジン（`formulas`）で実際に計算させて検証しています。

```bash
pip install openpyxl formulas
python build_xlsx.py magnet-nail-mri_workbook.xlsx
python inject_test.py      # 既知のテストデータを入れた verify.xlsx を作る
python verify.py           # 53項目の検算 + エラーセル走査
```

検証結果：**53/53 一致、エラーセル 0 件**（空の状態でもエラーなし）。
検算の内訳は、磁気力の計算、45°判定、平均・SD・95%信頼区間、最大値、
シーケンス別／TE別／距離別の集計、示温ラベルの温度範囲判定、
日数計算と中央値、延期率、部位別内訳、2×2表と感度・特異度・正確度です。

初回はお手元の Excel で開いて、集計値が意図どおりか確認してください。

## 行数の上限

02は400行、04は800行、06は150行、07は300行、09は200行、10は150行まで数式が入っています。
足りない場合は最終行を下方向にコピーしてください。

## 注意

- フォントは Meiryo 指定です。
- `03` と `05` の集計は範囲を固定しています。行を挿入する場合はデータ行の末尾より内側に。
- `03` は `01_試料マスタ` の先頭24件を自動参照します。25件以上は最終行を下にコピーしてください。
