# スライド

| ファイル | 内容 |
|---|---|
| `magnet-nail-mri_DUMMY.pptx` | 19枚の発表スライド。**数値・グラフ・画像はすべてダミー** |
| `build-deck.js` | 上記を生成するスクリプト（pptxgenjs） |

## これは何か

実験データが出る前に、**発表の流れと見え方を先に確認する**ための版です。
構成は `../PRESENTATION_PLAN.md` の「5. 発表スライドの骨組み」に対応しています。

数値が入っているスライドには右下に **「ダミー値」** バッジを付けてあります。
表紙と最終ページにも注意書きを入れてあるので、この状態で誤って発表される事故は起きません。

## 差し替えが必要な箇所

| 枚 | 内容 | 差し替え元 |
|---|---|---|
| 1 | 所属・氏名・発表先 | — |
| 2 | 延期件数・日数・脱落例・部位別割合 | 自施設の後ろ向き集計 |
| 3 | 各施設の対応 | 実在の公開文書（出典明記） |
| 10 | 偏向角の実測値 | 案A |
| 11 | **MRI画像（現状は模式図）** | 案B |
| 12 | TE依存の実測値 | 案B |
| 13 | 距離依存の実測値 | 案B |
| 14 | 配向別の値、示温ラベルの結果 | 案D・案C |
| 17 | 感度・特異度 | 案E-3 |
| 18 | 試験運用の前後比較 | 案E-5 |

11枚目は現状**模式図**（黒背景に信号消失を丸で表現）です。実画像に必ず差し替えてください。

## 作り直し方

```bash
npm install pptxgenjs
node build-deck.js magnet-nail-mri.pptx
```

数値はスクリプト内に直接書かれているので、実データが出たら該当箇所を書き換えて再生成できます。
PowerPoint で直接編集しても構いません。

## 注意

- 発表者ノートを各ページに入れてあります（何を強調するか、どこが山場か）。
- フォントは Meiryo 指定です。Mac で開く場合は游ゴシック等に置換してください。
- グラフはネイティブのPowerPointグラフなので、値をその場で編集できます。
