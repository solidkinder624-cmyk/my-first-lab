# 実験手順書（SOP）

| ファイル | 内容 |
|---|---|
| `magnet-nail-mri_SOP.docx` | 18章の実験手順書。印刷して現場で使う想定 |
| `build-sop.js` | 上記を生成するスクリプト（docx-js） |

## 構成

| 章 | 内容 |
|---|---|
| 1〜2 | 目的・適用範囲 |
| **3** | **安全上の遵守事項（8項目、例外なし）** |
| 4〜5 | 体制と役割・機材と消耗品 |
| 6 | 事前準備（試料作製、非磁性治具、ファントム、空間磁場勾配マップの確認） |
| 7 | 手順A　磁気吸引力（ASTM F2052 偏向角法） |
| 8 | 手順B　画像アーチファクト（ASTM F2119） |
| 9 | 手順C　発熱（示温ラベル法。規格非準拠である旨と限界を明記） |
| 10 | 手順D　配向異方性 |
| 11 | 手順E-1　延期症例の後ろ向き調査 |
| 12 | 手順E-3　簡易磁石テストの性能評価 |
| 13 | 測定順序とバイアス対策（無作為化・盲検化・反復数・記録のタイミング） |
| 14〜16 | データ管理・中止基準・撤収 |
| 17〜18 | 記録様式一覧（ワークブックの各シートに対応）・改訂履歴 |

冒頭に文書番号・版数・承認欄があり、そのまま院内文書として運用できます。

## 作り直し方

```bash
npm install docx
node build-sop.js magnet-nail-mri_SOP.docx
```
