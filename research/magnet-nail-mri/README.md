# マグネットネイル × MRI

マグネットネイル（磁性粉を含むジェルネイル）がMRI検査に与える影響を定量し、
「装着者は一律に延期して除去させる」という現行運用が妥当かを検証する研究の一式。

## 研究の骨子

現行の運用は施設ごとにばらついており、判断の根拠となる定量データが存在しない。
先行研究はアイメイクとタトゥーが中心で、ネイル、特に「磁石で整列させた状態」は手薄。

問いは3階層。

1. **物理** … どの経路で、どれだけ干渉するのか（吸引力／画像／発熱／配向）
2. **条件** … 磁場強度・シーケンス・距離でどう変わるのか
3. **運用** … では、どういうルールが妥当なのか

核心は **距離依存性**。撮影部位から十分離れていれば画像への影響は検出限界以下になるはずで、
そこが示せれば「手指・手関節は除去必須、頭部・体幹部は装着のまま実施可」という
部位別運用に置き換えられる。導入で出す延期症例の部位別内訳が、結論でそのまま回収される構造。

## 着手順

1. 延期症例の後ろ向き集計（実機不要。最優先）
2. 各装置の空間磁場勾配マップの確認（ガウスラインマップと取り違えないこと）
3. 供試製品の選定・購入、試料作製
4. 予備撮影で ImageJ の閾値処理手順を確立
5. 院内の承認手続き
